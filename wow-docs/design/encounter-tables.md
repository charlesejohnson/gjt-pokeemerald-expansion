# Encounter tables (generated)

Source list: `wow-docs/data/pokemon-stages.csv` (stage + rarity per species). Rebuilt by `wow-tools/rebuild_encounters.py` from the git version of `src/data/wild_encounters.json` (the script reads the file as it stands, so restore the JSON first before re-running).

- Time of day: `OW_TIME_OF_DAY_ENCOUNTERS` is on and the fallback is `TIME_DAY`. Each land map has a Day table (unsuffixed) and a `_Night` table; morning and evening use the Day table. Needs a working clock (RTC) in the emulator.
- Slots: 12 land slots (20/20/10/10/10/10/5/5/4/4/1/1). Common species fill the top slots, uncommon the middle, rare the 4% slots; extremely rare species (Mew, Jirachi, Landorus, Tornadus, Thundurus, Chi-Yu) are hand placed in the 1% slot only.
- Early routes (101-104, 116, 117, Petalburg Woods, Rusturf, Granite Cave) keep the Day tables as edited; only Night tables were added. Mid and late maps keep their first 2-3 original species (Day) and are rebuilt around the CSV list by type. Sea routes got new water and fishing tables (last slot kept: Wailmer/Sharpedo-type).
- Placements: Mew = Petalburg Woods night, Jirachi = Meteor Falls B1F 2R night, Landorus = Route 111 day, Tornadus = Route 113 day, Thundurus = Route 118 night, Chi-Yu = Fiery Path night. (Tornadus is also Prince Thunderaan's ace; change if that clashes.)
- Unown only appears in Mirage Tower and Route 111 night.
